    RTX 3050 GPU Optimization Lab

    79–87% cuBLAS · MNIST 98.6% · 先驗證才計時

    摘要
    在筆電 RTX 3050 上從零寫 CUDA／Triton kernel；每個 kernel 先驗證正確才計時，一行指令可重現。
    挑戰
    v2.0 自寫的 Softmax、LayerNorm 只有 57–67 GB/s，比 PyTorch 慢。
    解法
    改成一個 warp 處理一列：每列只讀一次 DRAM、用 128-bit 讀取 → 118 GB/s，比 PyTorch 快 1–6%。
    成果
    WMMA GEMM 達 cuBLAS 79–87%（2048³）；FP16 FlashAttention 比 SDPA 快 26%；pytest 129／129。QKV 仍慢 1–10%，照實列出。

    年化報酬率／退休規劃計算機

    5 種反推 · 通膨調整 · 可離線

    摘要
    多階段複利、CAGR／IRR 與退休目標的試算 App，可安裝到手機離線使用。
    挑戰
    常見做法把年報酬 ÷ 12 當月報酬，填 6% 實際會變成約 6.17%，結果偏高。
    解法
    預設改用有效年化：月報酬 = (1+r)1/12 − 1；進階設定可切回名目利率。
    成果
    5 種反推（金額／報酬率／定額／本金／時間）、多階段整體 IRR、退休規劃可反推幾歲能退休／每月要存多少／現在要有多少，含通膨與提領模擬；中英文介面。

    大師 13F 持股追蹤

    20 位大師 · 20 季 · 每天自動更新

    摘要
    自動抓 SEC 13F 申報，比對巴菲特等 20 位投資人每季的加減碼、跨大師共識與新買進，也能查某檔股票有哪些大師持有。
    挑戰
    外國公司（Chubb、ASML 等）的 CUSIP 是 CINS 格式，原本 568 檔全部對不到股票代號；Dorsey 最新一季約 33% 市值顯示不出代號。
    解法
    依 CUSIP 格式改用 CINS／ISIN 查 OpenFIGI；仍查不到的常見公司用人工對照表補上，每一筆都由測試核對申報上的公司名稱。
    成果
    最新一季沒有代號的市值降到 0.4% 以下（Burry 的特別股除外）；持股推估報酬對照 S&P 500、可離線瀏覽；290 個測試。

    04 / gpu-lab

    自學作品集 GPU Optimization Lab — RTX 3050 實作

    大三資工 · 依 8 週自學路線，從 vector add、matrix multiply、reduction，一路做到 PyTorch MNIST CNN、CUDA Extension 與 Triton kernel，全在筆電 RTX 3050 6GB 上實作。之後擴充為完整的 GPU 優化實驗室：FlashAttention、Transformer kernels、Roofline 分析，每個 kernel 都先驗證正確才計時，並可在 GitHub 一鍵重現。

    CUDA 12.4 PyTorch 2.6 + cuDNN C++ / CUDA Extension Triton Kernel FlashAttention
    Task Implementation Performance
    Matrix Multiplication WMMA Tensor Core tiled（2048³，FP16） cuBLAS 的 79–87%（6 次）
    Matrix Multiplication Triton（2048³，FP16） 14.0 TFLOPS（cuBLAS 14.4）
    Reduction Warp shuffle 對 shared-memory tree 1.68×（125 GB/s）
    MNIST CNN PyTorch GPU (SmallCNN + AMP) 98.6% test accuracy
    3×3 Conv Triton（B=128，FP16） 0.083 ms（cuDNN 0.168 ms）
    3×3 Conv CUDA Extension（B=32，FP32） 0.036 ms（cuDNN FP16：0.041–0.086 ms）
    FlashAttention S=4096 CUDA（FP32） 17.6 ms，同為 FP32 下比 SDPA（20.4 ms）快 14%
    FlashAttention S=4096 Triton（FP16） 2.45 ms，比 SDPA（3.30 ms）快 26%，誤差相同
    Softmax、LayerNorm CUDA warp-per-row（2048×768，FP16） 118 GB/s，比 PyTorch 快 1–6%（v2.0：57–67 GB/s）

    Device: NVIDIA GeForce RTX 3050 6GB Laptop GPU (Ampere sm_86)。每個 kernel 都先通過正確性檢查才計時，延遲為 3 輪中位數。CUDA QKV 仍比 PyTorch 慢 1–10%，完整結果見 GitHub。

    一鍵重現：python tools/performance_dashboard.py 跑完所有 benchmarks 並產出效能報告。
