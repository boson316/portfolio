Current Project

Research in Progress Undergraduate Research

Multimodal AI for Elderly Care

Speech · Facial Expression · Emotion Fusion · LLM · Edge AI

We are building an AI system for interacting with older adults. Our goal is to combine speech and facial expressions to estimate emotion, then use that result to guide an LLM’s response.

Goal
Use speech and expression to guide conversation
Target Platform
NVIDIA Jetson AGX Orin
My Role
Team Lead · five-person teamI handle NLP, emotion decision algorithms, system integration, and the frontend.
Current Progress
In development. No stable demo yet.
Project Details

The Problem

Speech and facial expressions can suggest different emotions. How should the system handle that disagreement, and how should its decision affect the LLM’s response?

Development Work

These are our current work items. Individual module status is still unconfirmed.

Open Questions

  1. Cross-dataset generalization: Do recognition results hold up on different data and in real interactions?
  2. Emotion fusion: What should happen when speech and expression disagree, or one signal is missing?
  3. Edge inference: Can the models run fast enough for conversation within Jetson’s memory limits?
  4. System integration: How do we connect the inputs, emotion decisions, and LLM, then track down delays and errors?

    RTX 3050 GPU Optimization Lab

    79–87% of cuBLAS · MNIST 98.6% · verified before timed

    Summary
    CUDA and Triton kernels written from scratch on a laptop RTX 3050; every kernel is verified before it is timed, and one command reproduces the run.
    Challenge
    In v2.0 my own Softmax and LayerNorm only reached 57–67 GB/s, slower than PyTorch.
    Fix
    One warp per row: each row is read from DRAM once with 128-bit loads → 118 GB/s, 1–6% faster than PyTorch.
    Result
    WMMA GEMM at 79–87% of cuBLAS (2048³); FP16 FlashAttention 26% faster than SDPA; pytest 129/129. QKV is still 1–10% slower, and the README says so.

    Guru 13F Holdings Tracker

    20 investors · 20 quarters · updated daily

    Summary
    Pulls SEC 13F filings automatically to compare quarter-over-quarter moves, cross-investor consensus and new buys for 20 investors such as Buffett, with a lookup for who holds a given stock.
    Challenge
    Foreign issuers (Chubb, ASML…) use CINS-format CUSIPs, so all 568 of them came back without a ticker; about 33% of Dorsey's latest quarter showed no ticker.
    Fix
    Query OpenFIGI by CINS or ISIN depending on the CUSIP format, and fill the remaining well-known names from a manual table whose every entry is checked against the filing's company name by a test.
    Result
    Value without a ticker in the latest quarter is now under 0.4% (except Burry's preferred stock); estimated returns vs the S&P 500, works offline; 290 tests.

    05 / gpu-lab

    Self-study GPU Optimization Lab — RTX 3050

    CS junior · An 8-week self-study plan, from vector add, matrix multiply and reduction to a PyTorch MNIST CNN, a CUDA Extension and Triton kernels — all on a 6GB RTX 3050 laptop GPU. Expanded into a full GPU optimization lab: FlashAttention, Transformer kernels and roofline analysis, with every kernel verified for correctness before it is timed, reproducible from GitHub.

    CUDA 12.4 PyTorch 2.6 + cuDNN C++ / CUDA Extension Triton Kernel FlashAttention
    Task Implementation Performance
    Matrix Multiplication WMMA Tensor Core, tiled (2048³, FP16) 79–87% of cuBLAS (6 runs)
    Matrix Multiplication Triton (2048³, FP16) 14.0 TFLOPS (cuBLAS 14.4)
    Reduction Warp shuffle vs shared-memory tree 1.68× (125 GB/s)
    MNIST CNN PyTorch GPU (SmallCNN + AMP) 98.6% test accuracy
    3×3 Conv Triton (B=128, FP16) 0.083 ms (cuDNN 0.168 ms)
    3×3 Conv CUDA Extension (B=32, FP32) 0.036 ms (cuDNN FP16: 0.041–0.086 ms)
    FlashAttention S=4096 CUDA (FP32) 17.6 ms, 14% faster than SDPA in FP32 (20.4 ms)
    FlashAttention S=4096 Triton (FP16) 2.45 ms, 26% faster than SDPA (3.30 ms) at the same error
    Softmax, LayerNorm CUDA warp-per-row (2048×768, FP16) 118 GB/s, 1–6% faster than PyTorch (v2.0: 57–67 GB/s)

    Device: NVIDIA GeForce RTX 3050 6GB Laptop GPU (Ampere sm_86). Every kernel passes a correctness check before timing; latencies are medians of 3 runs. CUDA QKV is still 1–10% slower than PyTorch; full results are on GitHub.
